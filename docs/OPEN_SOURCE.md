# 开源内容与隐私边界

本仓库是个人博客的开源实现，包含前端、内容 API、迁移、演示种子、公开作品集配置、第三方组件授权及开发说明。

## Fork 前需要替换

- `SITE_URL`：换成自己的域名，检查 canonical、站点地图和分享信息。
- CMS 内容：站点名称、项目、社交入口、法律页面和导航。不要将演示文字当作自己的经历。
- 源码中的公开作品集与品牌：包括 `work-showcase.tsx`、默认元数据和品牌图形。
- `api/src/services/github.ts`：已审查的仓库、作者、租户与特殊合入关联。它们是公开演示配置，不能直接当作自己的贡献。

## 不应发布

- 生产 `.env`、数据库 URL 中的真实凭据、管理密钥、SSH 私钥、会话 Cookie。
- 真实数据库导出、上传目录、私有笔记、客户资料、个人聊天或业务账户数据。
- 本机用户名及绝对路径、私网地址、个人服务器的地址与登录信息。

`.gitignore` 覆盖常见环境文件、私钥扩展名、数据库文件和运行数据目录，但忽略规则不能替代检查：已经被 Git 跟踪的文件仍会提交。每次发布检查精确 diff，并检查截图和附件。

## 保留的公开内容

作者署名、公开博客域名、GitHub 仓库和 PR 证据链接用于项目归属及贡献核验，不属于生产凭据。演示业务中台的登录信息仅用于仓库中的固定数据 Demo，不可复用为真实系统口令。MIT 与 React Bits 等第三方授权必须保留。
