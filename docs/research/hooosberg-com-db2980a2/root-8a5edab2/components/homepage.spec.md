# Homepage component specification

- Target: `src/components/hooosberg-clone.tsx`
- Interaction models: static content, hover navigation/cards, click theme and consent.
- DOM: header, hero, notes, products, directory, author/social, footer, consent.
- Typography, colors, spacing, states, and breakpoints are supplied by the preserved live CSS in `src/app/hooosberg-source.css`.
- Content: verbatim public homepage content captured 2026-08-25 for temporary emulation; it is intentionally scheduled for replacement before public use.
- Assets: one brand PNG, three product PNGs, nine social SVGs, all locally namespaced.
- Desktop: 1180px centered content and split/grid layouts.
- Mobile: 14px side gutters, single-column sections, full-width hero CTAs, wrapped navigation.
